# CelinesTools

Sammlung von Dalamud-Plugins fuer FFXIV, ueber ein gemeinsames Custom-Repository installierbar:

- [CelinesRPChat](CelinesRPChat/README.md) - RP-Chatfenster ohne Zeichenlimit
- [CelinesToolkit](CelinesToolkit/README.md) - Makro-Sequenzen aus mehreren Chat-Befehlen

## Installation

In Dalamud (`/xlsettings` -> Experimentell -> Custom Plugin Repositories) folgende URL eintragen:

```
https://raw.githubusercontent.com/CelineXIV/CelinesTools/main/pluginmaster.json
```

Danach erscheinen die Plugins einzeln im Plugin-Installer und lassen sich unabhaengig voneinander installieren/aktualisieren.
